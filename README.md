# График отпусков сотрудников администрации Сургутского района

Внутреннее веб-приложение для просмотра и анализа графиков отпусков.
Стек: **Nuxt 4, Vue 3, TypeScript, Nuxt UI 4**, серверная часть — Nuxt Server API (Nitro), БД — **SQLite**
(встроенный в Node.js модуль `node:sqlite`, внешние нативные пакеты не нужны).

## Запуск

Требуется **Node.js 22.13 или новее**.

```bash
npm install
npm run dev        # http://127.0.0.1:3000
```

Сборка и запуск в production-режиме:

```bash
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
npm run build
node .output/server/index.mjs
```

При первом запуске создаётся файл `data/vacations.sqlite`, и база автоматически заполняется
демонстрационными данными. Путь к файлу можно изменить переменной окружения `DB_PATH`.
Вернуть исходные данные можно кнопкой «Сбросить демо-данные» на странице «Подразделения»
либо удалением файла `data/vacations.sqlite*`.

## Страницы

| Адрес | Назначение |
| --- | --- |
| `/` | График отпусков: дерево подразделений, фильтры, диаграмма Ганта, сводка, анализ пересечений |
| `/employees` | Таблица сотрудников, поиск, фильтр по подразделению, добавление/правка/удаление |
| `/employees/:id` | Карточка сотрудника и его периоды отпусков |
| `/departments` | Просмотр и редактирование организационной структуры |
| `/vacations` | Таблица всех отпусков, создание и редактирование периодов |

## Возможности

- Дерево подразделений произвольной глубины; выбор узла показывает сотрудников узла и всех вложенных подразделений;
  сотрудники могут быть закреплены непосредственно за ОФО.
- Диаграмма Ганта: просмотр года или одного месяца, горизонтальная прокрутка, выходные, текущий день,
  несколько периодов у одного сотрудника, цвета по статусу, свёртывание подразделений, подробности по клику на полосу.
- Совместно работающие фильтры: подразделение, год и месяц, фамилия, «с отпусками», «без отпусков», «в отпуске на дату».
- Анализ пересечений по каждому подразделению (с учётом вложенных): период, число отсутствующих, их список,
  число работающих, предупреждение при превышении настраиваемого порога (по умолчанию 50 %).
- Сводка: всего сотрудников, в отпуске на дату, не в отпуске, без отпусков в году, максимум одновременно в отпуске.
- Светлая и тёмная темы, русский интерфейс, адаптивная вёрстка.

## API

| Метод | Адрес | Описание |
| --- | --- | --- |
| GET, POST | `/api/departments` | список / создание |
| PUT, DELETE | `/api/departments/:id` | изменение / удаление (нельзя при наличии вложенных или сотрудников) |
| GET, POST | `/api/employees` | список / создание |
| PUT, DELETE | `/api/employees/:id` | изменение / удаление (отпуска удаляются каскадом) |
| GET, POST | `/api/vacations` | список / создание |
| PUT, DELETE | `/api/vacations/:id` | изменение / удаление |
| POST | `/api/reset` | восстановление демонстрационных данных |

Серверная валидация: обязательные поля и длины, формат и существование дат, окончание не раньше начала,
период не длиннее 90 дней, допустимый статус, существование связанных записей, запрет пересечения периодов
одного сотрудника между собой, защита от циклов в иерархии подразделений.

## Тестовые данные

21 подразделение (5 ОФО, вложенность до 4 уровней), 71 сотрудник с вымышленными ФИО, 85 периодов отпусков:
у части сотрудников 2–3 периода, у части отпусков нет, есть несколько одновременных отпусков
(например, 4 из 5 сотрудников отдела планирования и анализа бюджета в июле 2026), отпуска через границу месяцев
и через границу 2026/2027 годов, сотрудники, закреплённые непосредственно за ОФО.
Генерация детерминированная — см. `server/utils/seed.ts`.
